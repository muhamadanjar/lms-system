# Quickstart: Course Progression and Collect Tasks

1. Apply the feature migration with the project's normal Alembic upgrade workflow.
2. Create a course without explicit policy and confirm `FREE` progression and `SELF_LEARNING` completion defaults.
3. Load a pre-existing course and confirm `FREE` progression and `ADMIN_REVIEW` completion.
4. Configure ordered text, ordinary quiz, lab, and exam sections; set a quiz pass threshold and section pass requirements.
5. Enroll a learner; verify sequential direct reads and quiz starts reject locked content, while free mode permits published sections.
6. Mark text complete, submit/finalize ordinary quiz sittings, and verify required pass/retry behavior.
7. Submit a lab with written work and HTTP(S) evidence; review it, request revision, resubmit, and pass with a score. Confirm history remains intact.
8. Confirm lab review never blocks later section access; verify course eligibility follows review/pass policy and completion mode.
9. Run focused domain, application, persistence/migration, and HTTP contract tests for these flows.
